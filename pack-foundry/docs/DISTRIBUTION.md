# Distribution and revenue — 2026-10-01

## Product promise

Ashfall Workshop publishes original, free Minecraft experiences with no end-user
account, email gate or tracking scripts. These five alpha downloads are free.
A free offering can help discovery; virality and revenue are not guaranteed.
The source repository is the coordination channel for agents. Do not distribute
private logs, tokens, save files, Minecraft binaries or other creators' assets.

## First catalogue

Signalkeepers is the adventure anchor. Field Instruments is its optional model
pack, not a standalone game. Trail Ledger rewards exploration, Hearthside adds
optional campfire rest, and Fieldcraft adds six survival recipes. They are
separate because their mechanics and use cases differ. Publish cosmetic variants
as files of one project, not duplicate marketplace listings.

## CurseForge preparation

All five projects are alpha candidates, not submitted or approved listings.
Before submitting each:

1. Run the build, release tests and disposable-server checks for Java 1.21.1.
2. Complete a human graphical playthrough, inventory/full-inventory checks,
   multiplayer checks and removal/reload checks. Record results in TESTING.md.
3. Capture real in-game images. The website illustrations are explicitly not
   gameplay and are not marketplace screenshots. Produce a 400×400 original icon.
4. Use the names, functionality, dependency and compatibility fields from
   catalog.source.json. Keep AI authorship disclosure visible and honest.
5. Create the correct project category (Data Packs or Resource Packs), choose
   Java 1.21.1, attach the per-project ZIP, set release type Alpha and MIT license,
   and include the source/issue links. Confirm current platform category options.
6. Resolve the actual project ID and current game-version ID from CurseForge.
   Store an API token only in a local credential store or GitHub Actions secret.
   Do not put a token in a manifest, URL, issue or agent prompt.
7. Upload only after the checks above. Record the resulting project/file IDs and
   moderation status. An API upload does not mean approved or publicly listed.
8. The owner can opt into rewards. Payouts require eligibility and sufficient
   popularity and have no fixed per-download rate.

Project descriptions and game-version selection remain reviewable in source.
No automated submission or payout account has been configured in this change.
The free GitHub catalogue can distribute the same original files without an
account; marketplace discovery is an additional route, not a prerequisite.

## Monetization boundaries

- Keep these Java downloads free. The Minecraft EULA restricts selling Java mods.
- Make original, free-to-view gameplay/commentary videos; ad monetization also
  requires the video platform's own eligibility.
- Bedrock Marketplace is a separate future product route requiring original
  Bedrock content, a portfolio, partner approval and submission review. These Java
  ZIPs cannot simply be uploaded as Bedrock add-ons.
- A future standalone creator-tool service, original generic 3D assets, or
  training could be evaluated separately. Nothing here creates a paid checkout.
- Use original settings and characters. Third-party franchise characters,
  copied mods, music and textures require appropriate rights.
- Modrinth currently restricts public projects primarily generated by AI.
  These substantially AI-built packs should not be assumed eligible. Disclosure
  or testing alone does not change authorship. Never conceal that origin.

## Sustainable cadence

Ship one tested improvement at a time. Keep one Minecraft version until the
catalogue has real players. Track downloads from available platform dashboards,
issues, repeat feedback, support effort and actual payouts. Avoid artificial
updates, duplicate variants and quantity targets that undermine quality.

Next substantial candidates: Canopy (original prehistoric exploration), a
village-rumour simulation, and an expanded Signalkeepers campaign. These are
backlog ideas, not implemented or advertised features.
