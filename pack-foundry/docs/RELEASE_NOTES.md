Five free Java 1.21.1 alpha packs: Signalkeepers, Field Instruments, Trail Ledger,
Hearthside and Fieldcraft. Download individual ZIPs or extract the collection
bundle first. No signup is required for public release assets.

Use a backed-up test world. Human graphical playtesting and full NeoForge stack
compatibility remain pending. These are data/resource packs, not loader mods.
See the repository's pack-foundry/docs/TESTING.md for actual validation evidence.

Each file includes publisher metadata and a license. Verify SHA256SUMS, then
verify GitHub build provenance with `gh attestation verify FILE -R
Arnie016/minecraft-server-studio`. A checksum alone does not prove authorship.

Code, writing and original models were substantially created with AI assistance.
Vanilla textures are referenced, not redistributed. Not an official Minecraft
product or associated with Mojang or Microsoft.
