# Minecraft Server Studio Plugin

Repo-local Codex plugin bundle for the standalone `minecraft-server-studio` repo.

This plugin is the Codex side of the product. The macOS menu bar app lives in:

- `/Users/arnav/Desktop/minecraft-server-studio/apps/minecraft-server-studio`

The plugin side lives here so Codex can work against the same repo and server context.

## Install On This Mac

```bash
cd /Users/arnav/Desktop/minecraft-server-studio
bash plugins/minecraft-server-studio/install-local-plugin.sh
```

Then fully quit and reopen Codex desktop.
